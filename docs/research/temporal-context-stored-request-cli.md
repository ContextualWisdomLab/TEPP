`lineageweave_temporal_context_stored_request_exchange` onto spawned
`tepp-loopback` TCP. HTTP semantics follow RFC 9110 (Fielding, Nottingham, &

scientific-authority promotion are repository contract (ADR 0092; ADR 0014).

`inference_status` on the live projection remains `temporal_association_only`.
`tepp.scientific_acceptance.v1` never appears. CLI success is not a scientific
claim.

persistence, Leiden, or an ADR 0014 claim-promotion package.
