# Retrospective-edge analysis-run composition

**Active slice:** ADR 0076 / `retrospective_edge_v1`
**Protected-main status:** not implemented-main

`retrospective_edge` already refuses to treat a later report about an
earlier event as a state transition or as a translation. This slice binds
`RetrospectiveKind`, `refuse_retrospective_as_transition`, and
`refuse_retrospective_as_translation` to a cutoff-safe analysis-run
profile so operators can request a digest-bound identity artifact.

The artifact inference status is
`retrospective_report_is_not_transition_and_not_translation`.
`identity_recovery_rate` stays library-side. This is not
role-contradiction, not subevent-containment, not inferred-status, not
episode-membership, not relation-absence, not outcome-order, not
membership-target, not location-membership, not membership-posterior ICC,
not copied-text, not copy-identity, not citation-edge, not GPU, not MCMC,
and not topic birth/split/merge.
