# Support-edge analysis-run composition

**Active slice:** ADR 0078 / `support_edge_v1`
**Protected-main status:** not implemented-main

`support_edge` already refuses to treat support, contradiction, summary,
and `outcome_of` as state transitions. This slice binds `EvidenceKind`
and `refuse_evidence_as_transition` to a cutoff-safe analysis-run
profile so operators can request a digest-bound identity artifact.

The artifact inference status is `evidence_is_not_transition`.
`edge_kind_recovery_rate` stays library-side. This is not
summarizes-edge, not retrospective-edge, not role-contradiction, not
subevent-containment, not inferred-status, not episode-membership, not
relation-absence, not outcome-order, not membership-target, not
location-membership, not membership-posterior ICC, not copied-text, not
copy-identity, not citation-edge, not GPU, not MCMC, and not topic
birth/split/merge.
