`tepp_api` now refuses any successful analysis-result summary whose `validation_status` is not the canonical `validated` state. Non-convergence, insufficient evidence, and unverifiable outcomes remain terminal failures with no measurement artifact, so a downstream temporal-analysis consumer cannot deserialize those states as a successful estimate merely by supplying a non-empty provider-authored status string. The TRSL topic-lineage executor now emits that same canonical successful state, preventing the stricter API contract from turning a genuinely converged owner result into an `InvalidWirePayload` failure.
