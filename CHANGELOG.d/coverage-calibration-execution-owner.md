# Scientific coverage calibration execution

- Opened #733 after tracing the prospective 10,000-DGP calibration path through #725-#732 and finding that the executable rolling-origin coverage composition still lived only in a `model_selection` integration test.
- Moved the realistic rolling-origin coverage DGP shape behind `CoverageCalibrationSimulationDesign::regression_config_for_seed` so CI-scale regression seeds use the same owner-defined event count, delays, Membership width, relation noise, method-effect rates, and known-topic DGP as the prospective scenario without reconstructing `SimulationConfig` arguments locally.
- `CoverageCalibrationSimulationDesign::config_for_replication` delegates to that same private DGP constructor while retaining sole authority for the prospectively declared replication ordinal -> seed mapping. The existing scenario fingerprint therefore remains bound to the same canonical configuration bytes.
- Added `analysis_engine::execute_coverage_calibration_replication` as the application/acceptance execution boundary. It accepts only the versioned simulation design and declared replication ordinal, composes canonical cutoff admission, multiple Membership, observed relation projection, truth-K recovery fitting, topic alignment, fit-bound marginal covariance, normal interval construction, and window coverage, then returns the exact indexed `CoverageCalibrationReplicationOutcome` consumed by persisted validation evidence.
- Only `ModelSelectionError::RecoveryCandidateFitFailed`, whose owner classifies non-convergence/non-finite/ALR numerical inability, becomes `numerical_failure(index)`. Structural simulation, split, Membership, relation, training, identity, alignment, covariance, and coverage failures propagate and invalidate the experiment instead of shrinking or contaminating the scientific denominator.
- Removed the caller-local `model_selection` interval-coverage orchestration after the owner executor landed, so a future sharded/resumable acceptance runner does not have to copy the CI test. The small executor contract remains separate from scientific promotion.
- The prospectively declared 10,000-DGP calibration study has still not been executed or persisted as schema-v4 acceptance evidence. No partial run is promoted, no post-hoc numerical-failure threshold is introduced, and exact-head hosted verification remains required.
