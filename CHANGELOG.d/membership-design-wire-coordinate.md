- `membership_core::MembershipDesignWire` now binds the Membership-owned design vocabulary version and design name as one typed coordinate. Supported names round-trip only under `tepp.membership_design.v1`; mismatched versions fail with `UnsupportedWireVersion` and unknown names fail with `UnknownMembershipDesign`. New analytical evidence must obtain that coordinate through `classify_membership_observations_wire`, which derives it from canonical Membership state; the raw design-to-wire constructor is crate-private so downstream callers cannot mint an apparently owner-issued classification from a freely chosen enum value.
