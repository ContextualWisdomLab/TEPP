- `membership_core::MembershipDesignWire` now binds the Membership-owned design vocabulary version and design name as one typed coordinate. Supported names round-trip only under `tepp.membership_design.v1`; mismatched versions fail with `UnsupportedWireVersion` and unknown names fail with `UnknownMembershipDesign`, so release consumers do not need to reconstruct the cross-field invariant themselves.
